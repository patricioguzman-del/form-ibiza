# FORM | ibiza website

New website for FORM | ibiza (formibiza.com). Built with Next.js 16, Tailwind CSS and TypeScript.

- Project rules: `CLAUDE.md`
- Technical plan and milestones: `docs/04-architecture.md`
- Design tokens: `styles/tokens.css` (from `docs/03-design-system.md`)

## Run it on a computer

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Checks: `npm run lint`, `npm run typecheck`, `npm run build`.

## Status

Milestone 1 (project shell) is done. Nothing is live: the site tells search engines not to list it until launch.
